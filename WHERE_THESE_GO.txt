Run these commands to restructure and push your real NurseSync repo
(this is a different repo than the demo one at ~/Desktop/nursesync —
clone it to a new folder so they don't collide):

  cd ~/Desktop
  git clone https://github.com/shivansh26sharma/NurseSync.git NurseSync-repo
  cd NurseSync-repo
  rm -rf docs

Now copy everything from this zip into NurseSync-repo, overwriting
README.md when asked. You should end up with:

  NurseSync-repo/
    doc/                              <- untouched, already there
    proposal/                         <- untouched, already there
    code/
      speech-to-text-demo/
        server.py
        index.html
        requirements.txt
    .github/workflows/                <- empty for now (.gitkeep placeholder)
    assets/                           <- empty for now
    docs/                             <- empty for now (old GitHub Pages content removed)
    journals/                         <- empty for now
    project-proposal/                 <- empty for now
    project-report-final/             <- empty for now
    project-report-prototype-stage/   <- empty for now
    .gitignore
    Makefile
    mkdocs.yml                        <- empty placeholder
    README.md

The .gitkeep files inside the empty folders are just there so git
actually tracks the empty directories (git ignores truly empty
folders otherwise). Delete a .gitkeep once you put real content in
that folder.

Then commit and push:

  git add -A
  git commit -m "Match course repo structure: add code/speech-to-text-demo and placeholder folders"
  git push
