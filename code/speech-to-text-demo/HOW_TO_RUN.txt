This replaces your previous single-page demo with a small multi-page
app: login -> dashboard -> patients -> patient (record/transcribe).

Files:
  login.html       - demo login (no real auth), goes to dashboard.html
  dashboard.html   - stats + recent handoffs (reads saved history)
  patients.html    - list of 3 patients, click one to open their page
  patient.html     - the working page: language selector, record,
                     editable transcript, save/copy, handoff history
  styles.css       - shared styling for all pages
  server.py        - backend (updated: now accepts a `language` field)
  requirements.txt

SETUP (same as before, in Terminal):
  cd ~/Desktop/nursesync        # or wherever your existing setup lives
  source .venv/bin/activate
  pip install -r requirements.txt   # only needed if requirements changed

Copy these new files into that same folder, overwriting the old
index.html/server.py etc. Then:
  uvicorn server:app --reload

Open login.html (double-click, or Live Server) and click through:
login -> Dashboard -> Patients -> pick a patient -> pick a language
(or leave "Auto-detect") -> Record Handoff.

History is saved in your browser's local storage per patient, so it
persists across reloads on your machine (not shared with anyone else,
and not stored on any server).
